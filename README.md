# Programme Muscu

Carnet de musculation sur téléphone : ton programme (créé à la main ou importé depuis le programme de ton coach), séances libres avec plus de 300 exercices, minuteur de repos, calendrier, progression par exercice et suivi du poids de corps.

**Ouvrir l'appli :** le lien GitHub Pages de ce dépôt, dans Safari sur iPhone, puis Partager → « Sur l'écran d'accueil ».

**Tes données** restent sur ton téléphone (rien n'est envoyé ailleurs). Pense à exporter une sauvegarde de temps en temps : onglet Progrès → « Exporter une sauvegarde complète ».

**Importer un programme :** accueil → « Programme » → photo, PDF ou texte. L'appli prépare une demande à coller dans ChatGPT (ou une autre IA), puis tu recolles sa réponse et tu vérifies avant d'enregistrer. Tu peux aussi créer ton programme à la main.
